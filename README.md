# financial-statement-analysis — 财务报表分析大师

基于清华大学出版社《财务报告分析（微课版）》系统化知识体系的财务报表分析 Skill。提供从报表解读、四大财务能力评价，到杜邦分析、沃尔评分、平衡计分卡及财务危机预警的全方位企业财务分析能力。

## 能力概览

- **报表解读**：资产负债表、利润表、现金流量表、所有者权益变动表的逐项分析与趋势解读
- **四大能力评价**：营运能力、盈利能力、偿债能力、发展能力的比率计算与判断
- **综合分析**：杜邦分析（ROE 分解）、帕利普分析、沃尔评分法、平衡计分卡
- **财务预警**：定性方法（四阶段症状、管理评分等）+ 定量模型（单变量、Z-score、Logistic）
- **报告生成**：按标准七段式模板输出结构化的财务分析报告
- **造假识别**：利润质量（利润 vs 现金流差异）、异常比率波动、关联交易、审计意见信号

## 知识来源

《财务报告分析（微课版）》，郭苏敬主编，清华大学出版社，2022 年 3 月第 1 版，ISBN 978-7-302-59891-6。全书 4 篇 12 章，462 千字。

## 分析哲学

像侦探一样阅读报表——不只计算比率，更要理解数字背后的商业故事。财务报告是企业的体检报告，分析是从数据还原真相的过程，每一项重大变动都在讲述企业的战略选择、经营效率和风险偏好。

## 标准报告模板

分析默认按七段式结构输出：一、分析背景与目的 → 二、企业概况与行业环境 → 三、财务报表解读 → 四、财务能力评价 → 五、综合分析（杜邦/沃尔/同业对比）→ 六、风险提示与财务预警 → 七、结论与建议。

## 关键分析原则

- **数据质量第一**：先验证报表口径、合并范围、会计政策一致性，再做比率计算
- **警惕盈余管理**：关注非经常性损益、收入确认时点、减值计提与转回等信号
- **现金流为锚**：利润需与经营活动现金流交叉验证，避免"纸面富贵"
- **结合行业与生命周期**：比率必须放在行业可比区间和企业所处阶段中判断
