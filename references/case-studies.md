## 案例一：家电三巨头对比分析 — 格力 vs 美的 vs 海尔 (2019年)

**教材位置**：第一章课后案例分析（第27页）

### 背景

国内家电市场2019年零售额同比下降3.82%，行业竞争愈发激烈。三家企业虽同为白色家电巨头，但发展路径各不相同。

### 关键数据 (2019年)

| | 格力电器 | 美的集团 | 海尔智家 |
|---|---|---|---|
| 营业收入 | 2005.08 亿元 | 2782.16 亿元 | 2007.62 亿元 |
| 收入同比增长 | +0.24% | +7.14% | +9.05% |
| 净利润 | 246.72 亿元 | 242.11 亿元 | 82.06 亿元 |
| 净利润同比增长 | −5.84% | +19.68% | +9.66% |
| 净利率（估算） | ≈12.3% | ≈8.7% | ≈4.1% |
| 业务结构 | 高度依赖空调 | 空调40% / 小家电40% / 其他20% | 全面均衡多元化 |

### 多维度对比分析

**盈利能力**：
- 格力净利率最高（≈12.3%），盈利能力突出
- 但高度依赖单一品类（空调），品类集中度风险
- 美的净利率中等（≈8.7%），但净利润增速最快（+19.68%）
- 海尔净利率最低（≈4.1%），需审视成本控制或产品溢价能力

**成长能力**：
- 海尔收入增速最快（+9.05%），美的紧随（+7.14%）
- 格力几乎零增长（+0.24%），且净利润下滑（−5.84%）
- 多元化布局的美的和海尔更具可持续增长潜力

**业务风险**：
- 格力：品类集中 → 抗行业周期波动能力弱，但专业性强
- 美的：收入结构稳健，小家电与空调互为补充
- 海尔：全球化均衡布局，抗风险能力强，但盈利效率待提升

### 2020年市值变动

美的市值增长800亿，格力"挥发"600亿，差距拉大至1500亿。市场对多元化企业的估值更高。

### 分析启示

1. **不能仅看单一指标**：格力净利率最高但市值增长最差，需要综合考量
2. **业务结构决定长期表现**：高利润率可能意味着聚焦战略成功，也可能意味着多元化不足的风险
3. **多元化提供稳定性**：多元化企业的收入更稳定，抗行业周期能力更强
4. **需结合企业战略定位**：不能简单以某一指标排名
5. **从财务报告分析角度对企业做出全面分析与评价**，需要涵盖本教材的全部四个维度：报表解读→财务能力→综合分析→风险预警

## 案例二：现金流组合模式判断（教材第五章应用）

### 场景A：成长期科技企业
```
经营现金流：−（抢占市场份额，大量营销和研发投入）
投资现金流：−（建设产能、购买设备、收购技术）
筹资现金流：+（股权融资为主，辅以银行授信）
```
判断：成长期/初创期典型特征。需要关注：融资可持续性、收入增速是否匹配投入、现金储备还能支撑多久。

### 场景B：成熟消费龙头企业
```
经营现金流：+（且持续大于净利润，折旧大）
投资现金流：−（维持性资本开支 + 适度扩张）
筹资现金流：−（大量分红 + 偿还债务）
```
判断：成熟期典范，财务最为健康。关注：分红是否可持续、资本开支是否足够维持竞争力。

### 场景C：衰退中的制造企业
```
经营现金流：−（收入持续下滑，成本费用刚性）
投资现金流：+（变卖固定资产、收回投资）
筹资现金流：+（借新还旧勉强维持）或 −（银行抽贷）
```
判断：危险信号。关注：是否具备业务转型能力、资产变现价值是否充足。

## 案例三：财务危机案例特征（教材第十二章应用）

### 四阶段症状模板

| 阶段 | 财务特征 | 非财务特征 |
|------|---------|-----------|
| **潜伏期** | 资产负债率开始上升，ROE 仍正常 | 盲目扩张、内部控制薄弱、战略方向不明 |
| **发作期** | 经营现金流转负，利润开始下滑 | 管理层频繁变动、核心员工离职 |
| **恶化期** | 流动比率 < 1，债务违约，连续亏损 | 供应商收紧信用、媒体报道负面 |
| **爆发期** | 资不抵债，利息保障倍数 < 1，Z-score < 1.81 | 被起诉、资产被查封、破产申请 |

### Z-score 预警实操

1. 收集最近3-5年的五大输入变量数据
2. 逐年计算Z值，观察趋势变化
3. 配合定性分析（审计意见、行业环境、管理层变动）综合判断
4. 若Z值连续下降并进入灰色区 → 需采取改善措施
5. 若Z值跨入危险区 → 立即启动危机应对预案

## 案例四：利润质量分析（教材第五章第7节应用）

### 情景：净利润与经营现金流的四种关系

| 关系 | 典型企业类型 | 判断 |
|------|-------------|------|
| 净利 > 0，经营现金流 > 净利 | 折旧大的重资产企业（如电力、高速公路） | 利润质量好，折旧为非付现费用 |
| 净利 > 0，经营现金流 ≈ 净利 | 成熟服务业 | 利润质量正常 |
| 净利 > 0，经营现金流 < 净利 | 快速扩张期企业（应收、存货大增） | 需具体分析，可能是成长性占用 |
| 净利 > 0，经营现金流 < 0 | 应收账款严重滞后、虚增收入 | 危险信号，利润质量差 |

### 分析关键

找出差异的主要来源：
- 若是应收/存货增加 → 评估是否与收入增速匹配（同步增长属正常，大幅超速则危险）
- 若是应付增加 → 是否供应商信用收紧的前兆
- 若是折旧摊销大 → 属于正常非付现项目，不影响利润质量
