# 财务比率公式速查手册

> 基于《财务报告分析（微课版）》全12章体系整理 — 对应 SKILL.md 第三篇（第7-10章）及第四篇第11章

---

## 一、营运能力（效率指标）— 第7章

### 存货管理
| 指标 | 公式 | 备注 |
|------|------|------|
| 存货周转率 | 营业成本 / 平均存货 | 平均存货 = (期初+期末)/2 |
| 存货周转天数 | 360 / 存货周转率 | 从入库到售出的平均天数 |

### 应收账款管理
| 指标 | 公式 | 备注 |
|------|------|------|
| 应收账款周转率 | 营业收入 / 平均应收账款 | 应收账款含应收票据，用坏账准备前原值 |
| 应收账款周转天数 | 360 / 应收账款周转率 | 平均回款周期 |

### 流动资产效率
| 指标 | 公式 |
|------|------|
| 流动资产周转率 | 营业收入 / 平均流动资产 |
| 流动资产周转天数 | 360 / 流动资产周转率 |

### 固定资产效率
| 指标 | 公式 |
|------|------|
| 固定资产产值率 | 总产值 / 平均固定资产原值 |
| 固定资产收入率 | 营业收入 / 平均固定资产净值 |
| 固定资产利润率 | 利润总额 / 平均固定资产净值 |

### 总资产营运
| 指标 | 公式 |
|------|------|
| 总资产产值率 | 总产值 / 平均总资产 |
| 总资产收入率（总资产周转率） | 营业收入 / 平均总资产 |
| 总资产周转天数 | 360 / 总资产周转率 |

### 周期分析
- **营运周期** = 存货周转天数 + 应收账款周转天数
- **应付账款周转天数** = 360 / (营业成本 / 平均应付账款)
- **现金周期** = 营运周期 − 应付账款周转天数
  - 现金周期越短 → 资金占用越少 → 营运效率越高
  - 现金周期为负 → 占用供应商资金经营（如大型零售企业）

## 二、盈利能力 — 第8章

### 2.1 资本经营盈利能力（投资者视角）
| 指标 | 公式 |
|------|------|
| **净资产收益率 (ROE)** | 净利润 / 平均净资产 × 100% |
| 普通股权益报酬率 | (净利润 − 优先股股利) / 平均普通股权益 × 100% |
| 净资产现金回收率 | 经营活动现金流量净额 / 平均净资产 × 100% |

### 2.2 资产经营盈利能力（全部资本视角）
| 指标 | 公式 |
|------|------|
| **总资产报酬率 (ROA)** | (利润总额 + 利息支出) / 平均总资产 × 100% |
| 总资产净利润率 | 净利润 / 平均总资产 × 100% |
| 资产现金回收率 | 经营活动现金流量净额 / 平均总资产 × 100% |

### 2.3 商品经营盈利能力（业务视角）
| 指标 | 公式 | 分析意义 |
|------|------|---------|
| **毛利率** | (营业收入 − 营业成本) / 营业收入 × 100% | 产品基本盈利空间 |
| 营业利润率 | 营业利润 / 营业收入 × 100% | 经营活动综合盈利 |
| 销售净利率 | 净利润 / 营业收入 × 100% | 最终盈利水平 |
| 成本费用利润率 | 利润总额 / (营业成本+税金及附加+销+管+财费用) × 100% | 成本费用投入产出比 |
| 息税前利润率 | (利润总额+利息支出) / 营业收入 × 100% | 便于跨行业/跨资本结构比较 |

### 2.4 上市公司专用指标
| 指标 | 公式 | 注意 |
|------|------|------|
| **基本每股收益 (EPS)** | 归母净利润 / 发行在外普通股加权平均数 | 加权平均反映年内变动 |
| 稀释每股收益 | 考虑可转债/认股权证/期权稀释效应 | ≤ 基本EPS |
| **市盈率 (P/E)** | 每股市价 / 每股收益 | 反映增长预期 |
| **市净率 (P/B)** | 每股市价 / 每股净资产 | 反映资产质量 |
| 市销率 (P/S) | 每股市价 / 每股营业收入 | 亏损企业可用 |
| 股利支付率 | 每股股利 / 每股收益 × 100% | 利润分配倾向 |
| 留存收益率 | 1 − 股利支付率 | 内部积累倾向 |
| 股息率 | 每股股利 / 每股市价 × 100% | 投资者现金回报 |

## 三、偿债能力 — 第9章

### 3.1 短期偿债能力
| 指标 | 公式 | 经验参考值 |
|------|------|-----------|
| **流动比率** | 流动资产 / 流动负债 | ≈ 2.0 (行业差异大) |
| **速动比率** | (流动资产 − 存货 − 预付账款) / 流动负债 | ≈ 1.0 |
| 保守速动比率 | (货币资金 + 交易性金融资产 + 应收款项) / 流动负债 | — |
| 现金比率 | (货币资金 + 交易性金融资产) / 流动负债 | > 0.2 |
| **经营现金流动负债比** | 经营活动现金流量净额 / 流动负债 | > 0.5 (最重要指标) |
| 营运资金（绝对额） | 流动资产 − 流动负债 | > 0 |

### 3.2 长期偿债能力
| 指标 | 公式 | 经验参考值 |
|------|------|-----------|
| **资产负债率** | 负债总额 / 资产总额 × 100% | 40%-60% (银行90%+特殊) |
| 产权比率 | 负债总额 / 所有者权益总额 × 100% | — |
| **权益乘数** | 资产总额 / 所有者权益 | = 1/(1−资产负债率) |
| 有形净值债务率 | 负债总额 / (所有者权益 − 无形资产 − 商誉) | 更保守 |
| **利息保障倍数** | (利润总额 + 利息费用) / 利息费用 | > 3 安全；< 1 危险 |
| 现金流利息保障倍数 | 经营活动现金流量净额 / 利息费用 | 比利润口径更可靠 |
| 长期资本负债率 | 非流动负债 / (非流动负债 + 所有者权益) | — |
| 长期负债与营运资金比率 | 长期负债 / (流动资产 − 流动负债) | < 1 较安全 |

## 四、发展能力 — 第10章

### 4.1 营业发展能力
| 指标 | 公式 |
|------|------|
| **营业收入增长率** | (本期 − 上期) / 上期 × 100% |
| 三年营业收入平均增长率 | [(期末/三年前)^(1/3) − 1] × 100% |
| 营业利润增长率 | (本期 − 上期) / 上期 × 100% |
| 净利润增长率 | (本期 − 上期) / 上期 × 100% |
| 总资产增长率 | (期末 − 期初) / 期初 × 100% |

### 4.2 财务发展能力
| 指标 | 公式 |
|------|------|
| 资本积累率 | (期末权益 − 期初权益) / 期初权益 × 100% |
| 资本保值增值率 | 期末权益 / 期初权益 × 100% (扣除客观因素) |
| **可持续增长率** | ROE × (1 − 股利支付率) = ROE × 留存收益率 |

可持续增长率可进一步分解为：
= 销售净利率 × 总资产周转率 × 权益乘数 × 留存收益率

## 五、综合分析关键公式 — 第11-12章

### 5.1 杜邦分析
```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/平均总资产) × (平均总资产/平均净资产)
```

### 5.2 因素分析法（连环替代法）
```
基期：A₀ × B₀ × C₀ = ROE₀
替代A：A₁ × B₀ × C₀ = ROE(a)   → A的影响 = ROE(a) − ROE₀
替代B：A₁ × B₁ × C₀ = ROE(b)   → B的影响 = ROE(b) − ROE(a)
替代C：A₁ × B₁ × C₁ = ROE₁    → C的影响 = ROE₁ − ROE(b)
验证：总变动 = A的影响 + B的影响 + C的影响 = ROE₁ − ROE₀
```

### 5.3 帕利普分析
```
可持续增长率 = ROE × 留存收益率
             = 销售净利率 × 总资产周转率 × 权益乘数 × (1 − 股利支付率)
```

### 5.4 沃尔评分
```
综合得分 = Σ(各指标权重 × 关系比率)
关系比率 = 实际值 / 标准值
```

### 5.5 Altman Z-score (制造业上市公司)
```
Z = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5
```
| 变量 | 公式 | 反映维度 |
|------|------|---------|
| X1 | (流动资产 − 流动负债) / 总资产 | 流动性 |
| X2 | (盈余公积 + 未分配利润) / 总资产 | 累计盈利能力 |
| X3 | (利润总额 + 利息费用) / 总资产 | 资产盈利能力 |
| X4 | 股东权益市值 / 总负债 | 财务结构 |
| X5 | 营业收入 / 总资产 | 资产周转效率 |

**判定区间**：>2.99 安全 / 1.81-2.99 灰色 / <1.81 危险

### 5.6 修正 Z-score (非制造业/非上市公司)
```
Z' = 0.717X1 + 0.847X2 + 3.107X3 + 0.420X4' + 0.998X5
```
其中 X4' = 所有者权益账面值 / 总负债

## 六、现金流量与利润关系公式 — 第5章

### 经营活动现金流量净额 = 净利润 + 调整项目
```
净利润
+ 资产减值准备
+ 固定资产折旧
+ 无形资产摊销
+ 长期待摊费用摊销
− 应收账款增加（+应收账款减少）
− 存货增加（+存货减少）
+ 应付账款增加（−应付账款减少）
+ 预收账款增加
+ 应交税费增加
= 经营活动现金流量净额
```

### 自由现金流量
```
自由现金流量 = 经营活动现金流量净额 − 资本性支出（维持性投资）
```
